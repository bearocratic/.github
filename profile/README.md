# Bearocratic

The opposite of bureaucratic, with one extra letter.

We build small, local-first software — tools that stay on your machine,
respect your time, and don't ask you to fill out a form to use them.

Out now: [den](https://github.com/bearocratic/den) — a terminal watcher for
the git repos in a folder. Open source under Apache-2.0.
[How we use it, daily →](https://bearocratic.dev/blog/den-every-day/)

The first product is close. When it's ready, you'll find it here.
